Field robotics

Weed Detection & Spraying — GPS-Guided Drone

View on GitHub
Working prototype

A GPS-guided drone that spots weeds from the air and sprays them directly, with no human in the loop. A YOLOv5 model running on a Raspberry Pi 4 and Pixhawk flight controller turns each detection into a real-world GPS coordinate, then commands the drone toward it and triggers the sprayer on arrival. Currently reaches 0.82 mAP@0.5 on the detection model; autonomous flight-to-target is still being finished.

Edge deployment

Vision-Based Precision Spraying — Jetson Deployment

View on GitHub
In development

A rebuild of the weed-spraying pipeline for an NVIDIA Jetson Orin Nano, running on DeepStream with a TensorRT-optimized YOLOv8 crop detector. Weed regions are found by segmenting green vegetation and excluding the crop area, entirely on the GPU using PyTorch/CUDA, before being converted into real-world coordinates for the sprayer controller.

Orchard Classification Using Satellite Imagery

View on GitHub

Mapping apple orchard canopy systems — V-trellis, vertical, and freestanding — across Washington's Yakima Valley using USDA NAIP aerial imagery. U-Net handles pixel-level segmentation of canopy architecture, while Mask R-CNN separates and classifies individual orchard structures, trained on 1,249 hand-labeled orchard instances.
